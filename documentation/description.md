## Description

FSL is developed as part of the SLE meets AI research initiative 
at the University of Koblenz under Professor Ralf Lämmel. 

FSL supports:
- Classification of software languages by type, paradigm, and formalism
- Alignment of software language knowledge with Wikipedia and DBpedia
- CI/CD based ontology engineering workflows
- AI-assisted ontology completion and validation

FSL uses standard semantic web technologies including OWL 2, 
RDF, SHACL, and SPARQL.
