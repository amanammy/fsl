# FSL — Foundations of Software Languages Ontology

## Abstract

The Foundations of Software Languages (FSL) ontology provides a 
formal machine-readable knowledge base capturing foundational 
concepts in software language engineering. FSL covers programming 
languages, modeling languages, configuration languages, and query 
languages, along with their paradigms, grammar formalisms, tools, 
and relationships to external knowledge sources such as Wikipedia 
and DBpedia.
